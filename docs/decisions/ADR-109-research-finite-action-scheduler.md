# ADR 109: Finite Research Action Scheduler

Date: 2026-10-06. Status: accepted for opt-in implementation.

Policy v5 freezes scheduler version 1. Use the registered planning/document/search/parse/digest/consolidate/reflection/evaluate/synthesis capabilities. Validate prerequisites before execution; retain immutable predecessor dependencies and input fingerprints in existing action receipts. Bound total actions to 64, unchanged afferent progress to three transitions, dynamic reroutes to three, and patch TTL to 1–3. Reject unsupported insert/remove semantics rather than pretending to execute them.

A deterministic projection of durable source content, segment IDs and contrary edges governs repeated reflection. The first pass frames. A second consecutive pass requires a newly witnessed contrary edge; a third is prohibited. A cache hit, refetch of identical content or model narrative cannot satisfy this gate. Unverified contrary links permit inspection without promoting semantic support. Conservative rejection routes to acquisition or explicit partial completion. Historical evidence and conflict remain available even when a current witness expires.

Persist guards and routing counters at the same checkpoint as the action receipt. Store final scheduler decisions in immutable action observations, with only the latest decision mirrored in task state. Existing policies remain unchanged. Repair pure-reflection mapping for both input and output, including critique/audit fields.

The existing provider attempt caps and task deadline remain shared across adaptive routes. This change establishes no live latency or semantic-quality benefit.
