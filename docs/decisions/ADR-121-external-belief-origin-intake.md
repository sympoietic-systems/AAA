# ADR-121: External belief origin intake

Status: accepted for local T8 implementation, 2026-10-09. Production enablement remains T18.

Document, shared-note and web creators retain separate origins through the injected origin-intake callback. Each origin has a strict boolean flag, default false. Migration 065's durable promotion marker prevents reopening a promoted origin's legacy creator when its flag is paused. The existing synchronous checkpoint is reused; perception handlers offload their complete synchronous use case once. No provider call, URL fetch or standing decision occurs at intake.

The document adapter reads the first stored parsed chunk in an owned conversation, bounded to 50,000 characters. Its file must be ready and the chunk transparent. The candidate retains at most 2,000 characters of that representation. Generated file summaries and the previous placeholder nomination are excluded from the promoted candidate statement. The representation hash binds the retained source snapshot; it does not authenticate original file bytes, authorship or the rest of the document. Local container ancestry is retained, with unavailable upstream identity visible. Further document context resolution belongs to T9.

Shared notes resolve the stored shared note and its parent message within the owned conversation. The selected quotation must occur in that message. The quotation becomes the observation; commentary remains separate in the rationale. The snapshot binds selection, commentary, parent identity and parent content hash. Missing, private, revoked, oversized or unsupported notes yield an unavailable-source observation without retaining caller-supplied selection/commentary. A note derived from a message does not become an independent source by passing through this adapter.

The web method currently has no durable upstream source record or application caller. The adapter retains its supplied excerpt with ambiguous upstream context; its hash binds the supplied representation only. URL-like identifiers remain labels. No upstream page is fetched, and content cannot issue instructions or confer authority. This is an implemented callable adapter, not evidence of an active web ingestion pipeline.

External encounters remain unscoped, awaiting context and abstained pending T9. Available owned chunk/note context is separate from unknown upstream independence. Missing/private sources and web excerpts retain missing/ambiguous context. T8 creates no semantic relations, independent support or adopted standing. Snapshot changes produce a new versioned encounter; exact retries reuse the original receipt. Completion rechecks document/note snapshots and conversation ownership under the existing writer transaction, recording stale on changed bindings. Web context remains explicitly unverified. Queue/checkpoint interruption uses existing T5 recovery; intake never automatically replays provider work.

Default-off document/web behavior remains legacy compatibility. Shared-note legacy storage keeps its historical message source, while the promoted route uses note identity. An unpromoted shared-note route cannot be reclassified as passive chat by the T7 callback. Existing structural accretion is legacy activity, not v2 independent support or adoption. T10 owns support accounting.
