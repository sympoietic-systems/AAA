# ADR-116: Belief review and situated standing contract

Status: accepted for staged implementation. Date: 2026-10-08.

Legacy crystallization, skill application and semantic review currently carry different authority histories. Mapping their labels directly to a shared adopted state would fabricate commitment provenance.

Freeze the [T3 contract](../architecture/BELIEFS_V2_CONTRACT.md): separate immutable encounters, advisory assessments, attributable decisions and situated standing. Reviewed commitment requires an operator adoption receipt bound to agent, record, statement hash and scope. Preserve legacy status with unknown canonical decisions; skill application does not transfer semantic adoption authority. Jev has no commitment write capability. Standing grants no tool execution authority.

Use versioned sidecars and extend the admission ledger in T5. Preserve bounded source snapshots, lineage uncertainty, scoped dissent, expected-version/hash commands, finite queues and visible deferral. Existing routes remain compatible; the reserved v2 namespace is implemented later. Origin promotion is durable so disabling a promoted origin cannot reopen a legacy bypass.

The [Symbia consultation and verification](../reports/048-belief-v2-contracts/README.md) support receipt binding and identify prompt-level erasure of dissent as a later evaluation obligation. Automatic calibrated adoption is excluded from the initial boundary. Typed models establish shape; persistence, authentication, replay evaluation and rollout remain separate gates in [BELIEF_SPEC.md](../systems/BELIEF_SPEC.md).

Consequence: T3 supplies executable contracts without enabling production behavior. T4 requires independently reviewed evaluation material; T5/T11/T12 must enforce database identity, transitions and snapshot export semantics.
